# LioraLang

[English](README.md) | **Русский** | [Polski](README.pl.md)

LioraLang помогает запоминать материал по своим карточкам. Создайте колоду, добавьте то, что хотите выучить, и повторяйте, когда придёт время. Приложение работает в браузере и на компьютере. Для локального обучения аккаунт не нужен.

[Открыть веб-приложение](https://liora-lang.vercel.app/app/learn) · [Скачать приложение](https://github.com/rorimark/LioraLang/releases/latest) · [Документация](docs/README.ru.md)

## Что можно учить

| Предмет | Что есть в карточке |
| --- | --- |
| Языки | Слово, перевод, третий язык при необходимости, примеры, уровень CEFR, часть речи, теги и изображения |
| Программирование | Термин или вопрос, ответ, необязательный код, сложность и заметки |
| Математика | Задача или правило, ответ, формулы LaTeX и шаги решения |
| История | Вопрос, контекст, ответ, дата и последствия |

У каждого предмета свои поля редактора и оформление карточек. В программировании используется спокойный дизайн редактора со вкладками технологий: SQL, CSS, PHP, JavaScript, Rust, Java, C++, C и C#. Можно указать и другую технологию.

Формулы отображаются в вопросах, ответах и пояснениях, а также в отдельном поле формулы. Код только показывается и не выполняется. Код и формулу можно поместить с вопросом или с ответом, чтобы не раскрывать решение раньше времени.

## Как пользоваться

1. Создайте или импортируйте колоду в разделе **Колоды**. Выберите предмет, а для неязыковой колоды ещё и язык ответов.
2. Добавьте карточки в редакторе или из раздела **Учить**. В языковую колоду можно вставить список слов.
3. Откройте ответ и оцените его: Again, Hard, Good или Easy. FSRS-5 назначит следующее повторение.
4. В **Прогрессе** смотрите активность, ближайшие повторения и заработанные стикеры.
5. Экспортируйте `.lioradeck`, чтобы поделиться колодой или сохранить её копию.

ИИ может предложить отдельную карточку или собрать колоду в специальном окне. Перед сохранением можно проверить и изменить все черновики. Главный переключатель и шесть переключателей функций находятся в **Настройках → ИИ-помощник**. Нужны аккаунт, интернет и остаток дневного лимита. Сейчас сервер разрешает 300 запросов на аккаунт в сутки по UTC; доступность модели может дополнительно ограничивать работу.

## Данные и работа без сети

Веб-приложение хранит колоды, журнал повторений и изображения в IndexedDB. Первый раз откройте его с интернетом, чтобы сохранить файлы приложения для работы без сети. Очистка данных сайта может удалить локальные колоды. Важный материал лучше экспортировать.

Десктоп использует SQLite. Готовые сборки есть для macOS на Apple Silicon и Windows x64. Они пока не подписаны. На macOS новую версию нужно скачивать вручную, поскольку автоматическая установка требует подписи.

Аккаунт нужен по желанию: он синхронизирует библиотеку и прогресс между устройствами. В публичный Hub пока можно публиковать только языковые колоды, включая колоды с картинками. Программирование, математика и история поддерживают экспорт и личную синхронизацию, но не публикацию в Hub.

Интерфейс переведён на английский, украинский, русский, польский, немецкий, испанский, французский, итальянский, португальский, турецкий, чешский и японский. Язык интерфейса, язык ответов и технология программирования выбираются независимо.

## Запуск проекта

Нужны Node.js от 22.12 и pnpm 10.33.0. Node.js 24 тоже подходит.

```sh
git clone https://github.com/rorimark/LioraLang.git
cd LioraLang
pnpm install --frozen-lockfile
pnpm dev:web
```

Откройте `http://localhost:5175`. Для Electron запустите `pnpm dev`. Если SQLite-модулю нужна пересборка, сначала выполните `pnpm rebuild:native`.

Для локального редактора и повторений ключи Supabase не нужны. Для аккаунта, Hub, синхронизации и ИИ нужны. Настройка, проверки и выпуск версий описаны в [руководстве разработчика](docs/onboarding.ru.md).
