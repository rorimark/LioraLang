# Подсказки для карточек (ИИ)

Человек вводит слово — приложение предлагает остальное: перевод (или слово на лицевую сторону, если введён перевод), перевод на дополнительный язык колоды, уровень CEFR, часть речи и два примера. При опечатке — «Может быть, …?».

Работает в редакторе колоды (строка добавления и правка слова) и в окне «Добавить слова».

## Как это выглядит

- Подсказка появляется в пустых полях «карандашом»: цветом акцента, с пунктиром, и тает, как только человек начинает печатать сам.
- `Tab` берёт всю подсказку, искра в конце поля — одно поле, `Esc` прячет. На телефоне — кнопка «Заполнить» в строке под полями.
- Пока ответ в пути, поля, которые он может заполнить, мерцают; взятое поле один раз «прокрашивается».
- Подсказка **никогда не перезаписывает** то, что человек ввёл или выбрал. Значение по умолчанию (например, уровень A1 из настроек), которое никто не трогал, заменить можно.
- Уровень и часть речи, взятые из подсказки, не переносятся на следующее слово; выбранные вручную — переносятся, как раньше.

## Устройство

```
браузер / десктоп                         Supabase                         Google
useWordSuggestion ──functions.invoke──▶  suggest-word (Edge Function) ──▶  Gemini API
  ▲   (токен пользователя)                 │ проверяет вход
  │                                        │ consume_word_suggestion()  (дневной лимит)
  └──── normalizeSuggestion ◀── JSON ──────┘ ключ GEMINI_API_KEY только здесь
```

- `packages/shared/src/core/usecases/wordSuggest` — чистая логика: о каком слове спрашивать, запрос, проверка ответа, какие поля можно заполнить. Одна и та же для web и desktop.
- `supabase/functions/suggest-word` — серверная функция. `gemini.ts` — запрос к Gemini и разбор ответа (без Deno, покрыт тестами), `index.ts` — обработчик.
- `packages/shared/src/api/createSupabaseWordSuggestApi.js` — вызов функции; сервис платформы `wordSuggestRepository`.
- `src/features/word-suggest` — хук и элементы интерфейса.
- Настройка: Settings → новые слова → «Подсказывать остальное в карточке» (`deckDefaults.wordSuggestions`, включена по умолчанию).

Почему функция Supabase, а не Vercel: десктоп пускает сетевые запросы только к доверенным адресам, и Supabase среди них уже есть; вход проверяется тем же токеном.

## Безопасность и приватность

- Ключ Gemini хранится только в секретах Supabase и в приложение не попадает.
- Подсказки получает только вошедший пользователь; без входа запросов нет совсем.
- Дневной лимит на человека — 300 подсказок (`consume_word_suggestion`, миграция `20261001_0004`). Пока миграция не применена, функция работает без лимита.
- В Google уходят только набранное слово и названия языков колоды. Названия языков проверяются, чтобы в запрос нельзя было вставить свои инструкции.
- На бесплатном тарифе Gemini Google может использовать запросы для улучшения своих продуктов. Описание настройки прямо говорит, куда уходит слово.

## Как включить

1. Создать ключ в Google AI Studio.
2. Supabase → Edge Functions → Secrets: `GEMINI_API_KEY` (обязательно), `GEMINI_MODEL` (по желанию). Без `GEMINI_MODEL` функция сама берёт новейшую стабильную Flash-модель из списка моделей Google, а если используемая модель пропала (404) — переключается на новую.
3. Применить миграцию `supabase/migrations/20261001_0004_word_suggestion_allowance.sql`.
4. Развернуть функцию `supabase/functions/suggest-word` с проверкой JWT.

Пока функция не развёрнута или ключ не задан, приложение молча работает без подсказок.
