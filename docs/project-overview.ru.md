# Что представляет собой Liora

[English](project-overview.md) | **Русский** | [Polski](project-overview.pl.md)

Liora помогает запоминать свой материал с помощью карточек и интервальных повторений. Основной цикл простой: добавить материал, вспомнить ответ, оценить себя, вернуться в назначенный день.

Проект подходит для слов и выражений, программирования, математических правил и задач, исторических событий и причинных связей. Пользователь сам выбирает материал или проверяет предложенные ИИ черновики.

## Название и совместимость

Публичное название продукта: **Liora**. Это приложение для запоминания материала по разным предметам с помощью карточек. Языки являются одним из предметов наряду с программированием, математикой и историей; новые профили позволят добавить другие.

Для совместимости сохранены технические имена: репозиторий GitHub и адрес сайта, пакет `liora-lang`, идентификатор десктопа `com.lioralang.app` и имена установщиков `LioraLang`. При смене публичного имени десктоп сохраняет прежнюю папку пользовательских данных. Файлы колод, хранилище браузера и идентификаторы синхронизации не меняются.

## Возможности версии 0.9.1

- Создание, редактирование, быстрое добавление, импорт и экспорт колод.
- Четыре предмета с разными полями и оформлением: языки, программирование, математика и история.
- FSRS-5, дневные лимиты, настройки сессии, свободный просмотр и дополнительная сессия.
- Изображения на языковых карточках и колоды с целой стороной из картинок.
- Формулы LaTeX в тексте математических карточек и отдельном поле формулы.
- ИИ для языковых подсказок, предложений неязыковых карточек и генерации колод с проверкой результата.
- Прогресс, календарь активности и стикеры за достижения.
- Необязательный аккаунт, личная синхронизация, список устройств и публичный Hub языковых колод.
- Веб-приложение с офлайн-кэшем, десктоп для macOS Apple Silicon и Windows x64.
- Светлая и тёмная темы, адаптивная навигация и 12 языков интерфейса.

## Как отличаются предметы

Языковая карточка строится вокруг слова и перевода. Программирование использует термин, вопрос и необязательный код в спокойной панели редактора. Математика показывает формулы и ход решения. История использует контекст, дату и последствия.

Предмет задаёт редактор и композицию карточки. Технология уточняет оформление программирования, но не создаёт отдельный предмет SQL, PHP или Rust. Произвольная технология работает через общий профиль Programming.

Язык интерфейса не задаёт язык ответов. У неязыковых колод есть отдельное поле языка содержимого; ИИ следует ему. Подробнее в [описании предметов](learning-objects.ru.md).

## Локальная и онлайн-части

Локально доступны редактор, просмотр, повторения, статистика и файлы колод. Веб хранит данные в IndexedDB, десктоп в SQLite. Для офлайн-запуска веба нужен первый визит с сетью.

Аккаунт, синхронизация, Hub и ИИ используют сервер. ИИ отправляет выбранный материал провайдеру и требует сети. Публичный Hub и личная библиотека являются разными функциями: личная синхронизация поддерживает все текущие предметы, Hub пока только языки.

## Границы продукта

Код в карточке не выполняется, формулы не решаются автоматически. ИИ может ошибаться, поэтому результат проверяют до сохранения. Нет встроенной локальной модели, генерации изображений, полноценного импорта PDF или автоматического извлечения карточек из произвольного сайта.

Очистка данных браузера может удалить локальную библиотеку. Экспорт переносит содержимое колоды, а не весь аккаунт. Одновременное редактирование на устройствах может создавать конфликтные копии. Десктопные сборки ещё не подписаны; на macOS установка обновления выполняется вручную.

## Как развивать

Новый предмет стоит добавлять, когда у него есть полезные отличия в полях или способе вспоминания. Новый профиль должен описывать эти отличия, работать без сети и проходить экспорт, импорт и синхронизацию. Общие сервисы и планировщик остаются общими.

Технические шаги описаны в [архитектуре](architecture.ru.md) и [предметах](learning-objects.ru.md). В [руководстве пользователя](user-guide.ru.md) показан обычный путь работы с приложением.
