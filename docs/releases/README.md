# История версий

Каждый файл описывает функции и ограничения своего релиза. Настройки ИИ, оформление и формат файлов менялись со временем, поэтому старое описание не является инструкцией для текущего приложения.

| Версия | Основные изменения |

| [0.8.3](v0.8.3.md) | Главный переключатель ИИ с сохранением отдельных предпочтений |
| [0.8.2](v0.8.2.md) | Раздельные настройки функций ИИ |
| [0.8.1](v0.8.1.md) | Язык ответов, выбор предмета в Learn и исправление подсказок |
| [0.8.0](v0.8.0.md) | Предложения программирования и картинки рядом со словом |
| [0.7.1](v0.7.1.md) | Сторона кода и улучшение формы Programming |
| [0.7.0](v0.7.0.md) | Предмет Programming и карточки с кодом |
| [0.6.0](v0.6.0.md) | Языковой ИИ, улучшение редактора, картинки и модерация Hub |
