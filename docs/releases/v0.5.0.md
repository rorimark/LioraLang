# LioraLang 0.5.0

This release brings a shared web and desktop app, FSRS-5 reviews, account sync and a new interface.

## Added

- Twelve interface languages: English, Ukrainian, Russian, Polish, German, Spanish, French, Italian, Portuguese, Turkish, Czech and Japanese.
- FSRS-5 scheduling in place of SM-2, with settings for the recall target and maximum interval.
- Optional account sync for decks and review progress, with local study available offline.
- A Devices section showing signed-in devices and their last sync time, with an option to remove a device.
- Quick add from a deck page or the study screen.
- Picture decks with images on either the front or the back. Images are resized, available offline, included in deck files and synced between devices.
- A public Hub with deck previews, one-click adding and a marker for decks already in the library.
- Progress with weekly activity, deck summaries and earned stickers.
- An installable web app with offline support after the first online visit.

## Improved

Learn uses an index-card layout, and stepping back returns a card to the deck. Deck rows show languages, learned counts, reviews due today and a Learn action.

Settings now use a searchable list of sections with current values. Account has Profile, Security, Devices and published Hub decks. Navigation appears as a side rail on wide screens and a bottom bar on phones. Pages load on demand.

## Fixed

Switching account tabs keeps the page and scroll position. Long tags and language names fit the deck list. Hub search includes descriptions as well as titles.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
