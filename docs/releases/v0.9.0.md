# LioraLang v0.9.0

Mathematics and History decks now have their own fields, card layouts and AI suggestions. Programming cards use a calm editor design that adapts to the deck technology.

- Mathematics: LaTeX formula preview, formula placement, solution steps and difficulty. Questions, answers and explanations also render inline `$...$` or `\(...\)` math and display `$$...$$` or `\[...\]` equations. Invalid notation remains editable text. Mathematical fonts and rendering work offline after the first visit.
- History: period or region, question context, date and consequences, with an archival card layout. Answer details stay hidden until the card is revealed.
- Programming: distinct file tabs and code-pane details for SQL, CSS, PHP, JavaScript, Rust, Java, C++, C and C#. Set the existing Technology field; there is no extra category selector. Other technologies keep the general Programming design.
- AI suggestions respect the selected answer language and technology. New subjects and technology appearances come from a shared extensible catalog.
- The Learn deck selector displays names at their proper width. Opening it with the keyboard no longer also flips the card.
- Language cards and SRS behavior are preserved. Mathematics and History deck packages require a client that supports package format 6; older clients reject them safely.

Validation: unit and integration tests, SQLite subject round trips, offline creation and learning, math rendering, and desktop/mobile checks in light and dark themes.

Known issues: desktop builds are not code-signed. macOS requires downloading the new release manually.
