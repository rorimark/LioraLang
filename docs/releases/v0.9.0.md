# LioraLang 0.9.0

**English** | [Русский](v0.9.0.ru.md) | [Polski](v0.9.0.pl.md)

Mathematics and History get their own fields, card layouts and AI suggestions. Programming adopts a calm editor design with technology-specific details.

## Subjects and cards

- Mathematics has a LaTeX formula preview, formula side, solution steps and difficulty. Questions, answers and explanations render inline `$...$` or `\(...\)` and display `$$...$$` or `\[...\]` math. Invalid notation stays editable text; rendering and fonts work offline after caching.
- History has a period or region, question context, date and consequences, with an archive-style layout. Answer details stay hidden until reveal.
- Programming has distinct tabs and code-pane details for SQL, CSS, PHP, JavaScript, Rust, Java, C++, C and C#. Use the existing Technology field; other technologies keep the general layout without another category selector.
- AI suggestions follow the answer language and subject context. Subject definitions and technology appearances come from an extensible shared catalog.

## Fixed and compatible

The Learn deck selector shows names at the intended width. Keyboard interaction with it no longer flips the card at the same time.

Language cards and SRS behavior are preserved. Mathematics and History use package format 6; older clients reject it safely.

Validation covered unit and integration tests, SQLite round trips, offline creation and learning, math rendering, and desktop/mobile layouts in light and dark themes.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
