# LioraLang v0.8.3

Settings → AI assistant now starts with a master switch for all AI. Individual function settings are available only when the master switch is on.

- Turning off the master switch stops pending requests and blocks all AI generation, including automatic hints and manual actions.
- Individual choices are saved while AI is off and restored when you turn it back on. The master state persists across restarts.
- The previous shared AI preference is respected during migration.
- All 12 interface languages include the new switch and explanation.

Known issues: desktop builds are not code-signed. macOS requires downloading the new release manually.
