# LioraLang 0.8.3

Settings → AI assistant now starts with a master switch. Individual function controls are available while it is on.

Turning off the master switch stops pending requests and blocks automatic hints and manual generation. Individual choices are kept and restored when AI is turned back on. The master setting also persists across restarts and respects the previous shared preference during migration.

All twelve interface languages include the switch and explanation.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
