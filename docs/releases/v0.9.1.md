# LioraLang 0.9.1

Generate a complete language, programming, mathematics or history deck in a dedicated AI window.

## Generation and editing

Choose the subject, topic, answer language, card count and level or difficulty. Set the technology or subject context where relevant. Programming accepts arbitrary technologies through its existing field.

Review the drafts before saving. You can edit questions, answers, code or formulas and their side, difficulty, historical context, notes and tags. Exclude or remove unwanted cards. Nothing is saved automatically.

On desktop, settings and drafts scroll independently. On mobile, the window uses a vertical layout with the final create action at the bottom.

Open it from **Decks → New deck → Collect a deck with AI** or **Learn → Add card → Generate a deck**. The main AI switch and Generate decks by topic both control access. Sign-in, allowance, cancellation and errors use the existing server flow.

The deck and selected cards save together. After saving, they work offline and keep their subject layout, code or formula side and answer language. Language cards and SRS behavior are preserved.

## Validation

The release passed 544 unit and integration tests, SQLite subject checks and browser scenarios for the new subjects and language generation. The scenarios covered draft editing, persistence, stale replies, quota, AI settings and mobile layout.

Browser acceptance used controlled API responses rather than a real provider or account allowance. It verifies the workflow, not factual quality of generated material.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
