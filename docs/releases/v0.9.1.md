# LioraLang v0.9.1

Generate complete decks for Programming, Mathematics and History in a dedicated AI workspace. Language deck generation uses the same window.

- Choose a subject, technology or subject context, topic, answer language, difficulty and card count. Programming supports arbitrary technologies through its existing Technology field; subject generation is enabled by the shared profile catalog.
- Review and edit questions, answers, code or formulas and their side, difficulty, historical context, notes and tags. Exclude or remove drafts before creating the deck. Nothing is saved automatically.
- Deck settings and card review scroll independently on desktop. Mobile uses a single vertical layout with the final creation action pinned at the bottom.
- Open the workspace from **Decks → New deck → Collect a deck with AI** or **Learn → Add card → Generate a deck**.
- Both the main AI switch and the separate **Generate decks by topic** setting control this feature. Sign-in, daily allowance, cancellation and errors use the existing authenticated server path.
- The deck and selected cards save together. Saved cards work offline and keep the subject layout, code/formula placement and answer language. Language cards and SRS behavior are preserved.

Validation: 544 unit and integration tests, SQLite subject checks, deterministic desktop/mobile generation and editing flows for the new subjects, language generation, stale-response cancellation, quota and AI settings. Browser acceptance uses controlled API responses rather than a real provider or account quota.

Known issues: desktop builds are not code-signed. macOS requires downloading the new release manually.
