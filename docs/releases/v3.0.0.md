## What’s New in v3.0.0

LioraLang 3.0 is a rebuild of almost everything you see and a new scheduler underneath it. The same app now runs on the web and on the desktop, speaks twelve languages, and keeps your decks in step across devices.

### Added

- The interface in 12 languages: English, Ukrainian, Russian, Polish, German, Spanish, French, Italian, Portuguese, Turkish, Czech and Japanese
- Reviews scheduled with FSRS-5 instead of SM-2, with your own recall target and longest gap in Settings
- An account with offline-first sync: decks and progress follow you between the web and the desktop app
- A Devices section that shows where you are signed in, when each device last synced, and lets you remove the ones you no longer use
- Quick add: put words into a deck straight from the deck page or the study screen
- LioraLang Hub: browse public decks, preview them, add one in a click and see which ones are already in your library
- Stickers for what you have done, and a progress page with weekly activity and your decks at a glance
- A web version you can install as an app and use offline

### Improved

- Learn: the card behaves like a real index card, and stepping back returns it to the deck
- Decks: each deck shows its language pair, how much is learned, what is due today, and a Learn button
- Settings: one list of sections that says what each is set to, with search
- Account: one page with Profile, Security, Devices and your Hub decks
- Navigation: a rail on wide screens and a tab bar on phones
- Pages load on demand, so the app starts faster

### Fixed

- Switching tabs on the account page no longer reloads it or loses your scroll position
- Long tags and language names no longer break the deck list
- Hub search matches descriptions as well as titles

### Known issues

- The builds are not code-signed yet. Windows may show Unknown Publisher; on macOS, open the app the first time with right-click → Open.
- On macOS the update cannot install itself while the app is unsigned. Download the new version from this page.
