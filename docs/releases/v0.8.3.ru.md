# LioraLang 0.8.3

[English](v0.8.3.md) | **Русский** | [Polski](v0.8.3.pl.md)

«Настройки → ИИ-помощник» теперь начинаются с главного переключателя. Отдельные функции доступны, пока он включён.

Выключение главного переключателя останавливает ожидающие запросы и блокирует автоматические подсказки и ручную генерацию. Индивидуальный выбор сохраняется и восстанавливается при включении ИИ. Главное состояние сохраняется между запусками и при миграции учитывает прежнюю общую настройку.

Переключатель и пояснение доступны на всех двенадцати языках интерфейса.

## Известные проблемы

Десктопные сборки не подписаны. Windows может показывать Unknown Publisher. На macOS при первом запуске откройте приложение через контекстное меню.

Неподписанное приложение macOS не может устанавливать обновления автоматически. Скачайте новую версию со страницы релиза.
