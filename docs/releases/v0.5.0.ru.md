# LioraLang 0.5.0

[English](v0.5.0.md) | **Русский** | [Polski](v0.5.0.pl.md)

Это версия с общим веб- и десктопным приложением, повторением FSRS-5, синхронизацией аккаунта и новым интерфейсом.

## Добавлено

- Двенадцать языков интерфейса: английский, украинский, русский, польский, немецкий, испанский, французский, итальянский, португальский, турецкий, чешский и японский.
- Планирование FSRS-5 вместо SM-2, настройки целевой вероятности вспоминания и максимального интервала.
- Необязательная синхронизация колод и прогресса через аккаунт, с локальной учёбой без сети.
- Раздел «Устройства» с активными устройствами, временем последнего обмена и удалением устройства.
- Быстрое добавление со страницы колоды или экрана учёбы.
- Картинные колоды с изображением на лицевой или оборотной стороне. Изображения уменьшаются, доступны офлайн, входят в файлы колод и синхронизируются между устройствами.
- Публичный Hub с предпросмотром, добавлением одним нажатием и отметкой уже добавленных колод.
- Прогресс с недельной активностью, сводками колод и полученными стикерами.
- Устанавливаемое веб-приложение с офлайн-работой после первого визита с сетью.

## Улучшено

Learn использует бумажную карточку; шаг назад возвращает карточку в колоду. Строки колод показывают языки, число изученных карточек, повторения на сегодня и действие «Учить».

Настройки получили поиск по разделам и отображение текущих значений. В аккаунте есть профиль, безопасность, устройства и опубликованные колоды Hub. На широком экране навигация сбоку, на телефоне снизу. Страницы загружаются по мере необходимости.

## Исправлено

Переключение вкладок аккаунта сохраняет страницу и прокрутку. Длинные теги и названия языков помещаются в списке колод. Поиск Hub учитывает описания вместе с названиями.

## Известные проблемы

Десктопные сборки не подписаны. Windows может показывать Unknown Publisher. На macOS при первом запуске откройте приложение через контекстное меню.

Неподписанное приложение macOS не может устанавливать обновления автоматически. Скачайте новую версию со страницы релиза.
