# LioraLang 0.8.0

This release adds AI suggestions for programming cards and optional images alongside ordinary language cards.

## Programming suggestions

Ask for up to three suggestions from a term, question or code in the editor or Quick add. Review the answer, code side, difficulty, notes and tags before applying a suggestion. Only empty fields are filled, and saving remains a separate action.

The feature uses the existing account and daily allowance. Offline, sign-in, quota and error states are shown. Editing or switching decks discards late replies. Programming review stays local and does not call AI.

## Images on language cards

An ordinary language card can now include a picture beside its word and translation. Session settings offer Text → translation or Picture → word. Cards without a picture use text, and both presentations share one review schedule.

The feature reuses image storage, sync and export from picture-side decks.

## Subject profiles

Profiles describe fields, layouts, study presentations and separate AI capabilities. Forms and AI validation use shared field definitions. The subject picker supports a longer catalog, and import rejects unknown subjects instead of dropping their fields.

## Compatibility

Language cards with optional images use package format 4. Older apps reject these packages to avoid losing pictures. Ordinary language decks remain format 1. Programming uses format 2 or 3 according to code placement.

SRS and FSRS scheduling are unchanged.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
