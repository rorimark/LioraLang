## What’s New in v0.8.0

### Card suggestions for programming

- Ask for up to three card suggestions from a term, question or code in the editor and Quick add
- Review the answer, code placement, difficulty, notes and tags before applying
- Fill only empty fields, preserving everything you wrote; save the card when ready
- Clear offline, sign-in, quota and error states; late replies are discarded when you edit or switch decks
- Existing AI sign-in and daily allowance apply. Programming review remains local and never asks AI

### Optional pictures on language cards

- Add a picture alongside the word and translation in an ordinary language deck
- Choose Text → translation or Picture → word in session settings; cards without a picture use text
- Both presentations share the same review schedule
- Existing picture-side decks, image storage, sync and export are reused

### A foundation for more subjects

- Separate profiles describe fields, layouts, study presentations and independent AI capabilities
- Forms and AI validation share the same field definitions
- A subject picker that scales to a longer list; unknown subjects are rejected on import instead of losing their fields

### Compatibility and known issues

- Text decks with optional pictures use package format 4 and require this version or the updated website. Older apps reject them rather than erase the pictures
- Ordinary language packages remain format 1. Programming packages remain format 2 or 3, depending on code placement
- SRS and FSRS scheduling are unchanged
- Desktop builds are not code-signed. Windows may show Unknown Publisher; on macOS, use right-click → Open on first launch
- The unsigned macOS app cannot install updates automatically. Download this version from the release page
