# LioraLang 0.7.0

[English](v0.7.0.md) | [Русский](v0.7.0.ru.md) | **Polski**

Programowanie staje się pierwszym przedmiotem obok nauki języków. Talie programowania działają offline z własnym wyglądem kart.

## Dodano

Karta programowania zawiera termin lub pytanie, odpowiedź, opcjonalny kod, trudność i notatki. Zamiast pary języków talia przechowuje technologię, np. JavaScript lub SQL. Wybierz Programowanie w edytorze.

Learn pokazuje pytanie i kod z numerami linii albo duży termin bez kodu. Tył pokazuje odpowiedź i pomocniczy fragment. Kod jest wyświetlany, nigdy wykonywany.

Talie językowe pozwalają wybrać język nauki. Wskazówki po błędzie uwzględniają wybór i kierunek karty. Szybkie dodawanie tworzy talię obrazkową z obrazami po dowolnej stronie. Asystent proponuje opis i tagi talii, a ustawienia pokazują pozostały dzienny limit.

## Poprawiono

Szybkie dodawanie zachowuje pola poza dwiema stronami tekstowymi. Przy tworzeniu talii jasno wskazuje brak nazwy i przenosi fokus do jej pola.

## Zgodność

Talie programowania wymagają tej lub nowszej wersji na każdym urządzeniu. Starsze klienty odrzucają nowy format zamiast odczytywać go jako talię językową i tracić kod. W tej wersji programowanie nie korzysta z AI i nie można go publikować w Hub.

## Znane problemy

Wydania desktop nie są podpisane. Windows może pokazywać Unknown Publisher. Na macOS przy pierwszym uruchomieniu otwórz aplikację przez menu kontekstowe.

Niepodpisana aplikacja macOS nie może automatycznie instalować aktualizacji. Pobierz nową wersję ze strony wydania.
