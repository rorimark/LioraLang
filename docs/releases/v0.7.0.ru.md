# LioraLang 0.7.0

[English](v0.7.0.md) | **Русский** | [Polski](v0.7.0.pl.md)

Программирование становится первым предметом помимо изучения языков. Колоды программирования работают офлайн со своим оформлением карточек.

## Добавлено

Карточка программирования содержит термин или вопрос, ответ, необязательный код, сложность и заметки. Вместо языковой пары колода хранит технологию, например JavaScript или SQL. Выберите «Программирование» в редакторе.

Learn показывает вопрос и код с номерами строк либо крупный термин без кода. На обороте ответ и вспомогательный фрагмент. Код только отображается, никогда не выполняется.

В языковых колодах можно выбрать изучаемый язык. Подсказки после ошибки учитывают этот выбор и направление карточки. Быстрое добавление создаёт картинную колоду с изображением на любой стороне. Помощник предлагает описание и теги колоды, настройки показывают остаток дневной квоты.

## Исправлено

Быстрое добавление сохраняет поля помимо двух текстовых сторон. При создании колоды оно явно сообщает об отсутствующем имени и переводит фокус в поле названия.

## Совместимость

Колоды программирования требуют эту версию или новее на каждом устройстве. Старые клиенты отклоняют новый формат вместо чтения как языковой колоды с потерей кода. В этой версии программирование не использует ИИ и не публикуется в Hub.

## Известные проблемы

Десктопные сборки не подписаны. Windows может показывать Unknown Publisher. На macOS при первом запуске откройте приложение через контекстное меню.

Неподписанное приложение macOS не может устанавливать обновления автоматически. Скачайте новую версию со страницы релиза.
