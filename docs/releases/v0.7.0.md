# LioraLang 0.7.0

Programming becomes the first subject alongside language learning. Programming decks work offline with their own card layout.

## Added

A programming card contains a term or question, answer, optional code, difficulty and notes. The deck stores a technology such as JavaScript or SQL instead of a language pair. Choose Programming in the deck editor.

Learn shows the question and a numbered code pane, or a large term when there is no code. The back shows the answer and supporting snippet. Code is displayed, never executed.

Language decks can select which language is being learned. Hints after a missed card follow that choice and the direction shown. Quick add can create a picture deck with images on either side. The assistant can suggest a deck description and tags, and Settings show the remaining daily allowance.

## Fixed

Quick add preserves fields beyond the two text sides. It also makes a missing name clear when creating a new deck and focuses the name field.

## Compatibility

Programming decks require this version or newer on each device. Older clients reject the new package format rather than treating it as a language deck and losing code. In this release, programming decks do not use AI and cannot be published to the Hub.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
