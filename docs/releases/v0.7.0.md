## What’s New in v0.7.0

LioraLang 0.7 is the first version that remembers more than languages: programming decks, with cards built around code.

### Added

- Programming decks: choose Programming when you create a deck. A card is a term or a question, its answer, an optional piece of code, a difficulty and notes. The deck has a technology, such as JavaScript or SQL, instead of two languages
- Programming cards in Learn have their own layout: the question above a numbered code pane, a term on its own as the headline, and the answer first on the back with the snippet under it. Code is shown exactly as written and is never run
- Choose which language of a deck you are learning, in the deck’s settings. Hints after a missed card explain that language
- Make a new deck a picture deck straight from Add words, with pictures on the front or the back
- The assistant describes and tags decks, and Settings show how much of today’s allowance is left

Programming decks work fully offline. The assistant is not used for them, and they cannot be published to the Hub yet.

### Improved

- Add words makes it clear that a new deck needs a name, and takes you to the field
- Hints after a missed card explain the word you were asked about, in the direction it was shown

### Fixed

- Adding words from Add words no longer drops anything a card holds beyond its two sides

### Known issues

- Programming decks need this version on every device. Older versions refuse them instead of opening them as language decks, so nothing is lost; update each device to see them.
- The builds are not code-signed yet. Windows may show Unknown Publisher; on macOS, open the app the first time with right-click → Open.
- On macOS the update cannot install itself while the app is unsigned. Download the new version from this page.
