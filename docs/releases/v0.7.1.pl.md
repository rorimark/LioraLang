# LioraLang 0.7.1

[English](v0.7.1.md) | [Русский](v0.7.1.ru.md) | **Polski**

Karty programowania łatwiej tworzyć, a kod może należeć do pytania albo odpowiedzi.

## Ulepszono

- Menu nowej talii oferuje Programowanie bezpośrednio, a edytor zaczyna od wyboru przedmiotu.
- Pola odpowiadają kolejności karty: termin lub pytanie, opcjonalny kod, wielowierszowa odpowiedź.
- Kod może być Z pytaniem lub Z odpowiedzią. Kod odpowiedzi pozostaje ukryty do odwrócenia.
- Długie linie zawijają się do szerokości, z numerem na początku każdej oryginalnej linii.
- Enter dodaje linię odpowiedzi, Ctrl/Command + Enter dodaje kartę.
- Edytor, szczegóły talii i Learn używają etykiet kart programowania we wszystkich dwunastu językach.

## Poprawiono

Ponowne otwarcie offline zachowuje style w pamięci podręcznej także przy innych nagłówkach żądania. Szybkie dodawanie zachowuje kod i jego stronę, nie traktuje programowania jak listy słówek. Dodaj kartę mieści się na zwartym poziomym pasku. Lokalny podgląd nie żąda już skryptu analityki dostępnego tylko na Vercel.

## Zgodność

Kod po stronie odpowiedzi używa formatu pakietu 3 i wymaga 0.7.1 lub zaktualizowanej strony. Starsze aplikacje odrzucają pakiet zamiast ujawniać odpowiedź. Pozostałe talie programowania zachowują format 2, językowe format 1.

Karty językowe i planowanie SRS pozostają bez zmian. Programowanie działa bez usługi AI.

## Znane problemy

Wydania desktop nie są podpisane. Windows może pokazywać Unknown Publisher. Na macOS przy pierwszym uruchomieniu otwórz aplikację przez menu kontekstowe.

Niepodpisana aplikacja macOS nie może automatycznie instalować aktualizacji. Pobierz nową wersję ze strony wydania.
