# LioraLang 0.8.2

[English](v0.8.2.md) | **Русский** | [Polski](v0.8.2.pl.md)

Функции ИИ получили отдельные переключатели в «Настройки → ИИ-помощник».

Автоматические предложения слов и пояснения после Again настраиваются отдельно от предложений карточек, дополнения списка, генерации по теме и описания колоды. Отключение функции отменяет её запрос и блокирует поздний результат; другие включённые функции остаются доступны.

Выбор сохраняется между запусками. Если ИИ был отключён, эта версия оставляет все шесть функций выключенными до их отдельного включения. Настройки различают автоматические действия и запросы по кнопке, показывают общую дневную квоту. Новые контроли переведены на все двенадцать языков.

## Известные проблемы

Десктопные сборки не подписаны. Windows может показывать Unknown Publisher. На macOS при первом запуске откройте приложение через контекстное меню.

Неподписанное приложение macOS не может устанавливать обновления автоматически. Скачайте новую версию со страницы релиза.
