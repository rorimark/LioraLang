# LioraLang 0.7.1

[English](v0.7.1.md) | **Русский** | [Polski](v0.7.1.pl.md)

Карточки программирования стало удобнее создавать, код может относиться к вопросу или ответу.

## Улучшено

- Меню новой колоды предлагает программирование напрямую, редактор ставит выбор предмета первым.
- Поля идут в порядке карточки: термин или вопрос, необязательный код, многострочный ответ.
- Для кода выбирается «С вопросом» или «С ответом». Код ответа скрыт до переворота.
- Длинные строки переносятся по ширине, номер остаётся в начале каждой исходной строки.
- Enter добавляет строку в ответе, Ctrl/Command + Enter добавляет карточку.
- Редактор, страница колоды и Learn используют подписи карточек программирования на всех двенадцати языках.

## Исправлено

Повторное открытие офлайн сохраняет кэшированные стили даже при отличающихся заголовках запроса. Быстрое добавление сохраняет код и его сторону, не разбирает программирование как словарный список. «Добавить карточку» помещается в компактном горизонтальном тулбаре. Локальный предпросмотр больше не запрашивает скрипт аналитики, доступный только на Vercel.

## Совместимость

Код на стороне ответа использует формат пакета 3 и требует 0.7.1 или обновлённый сайт. Старые приложения отклоняют пакет вместо раскрытия ответа. Другие колоды программирования остаются в формате 2, языковые в формате 1.

Языковые карточки и планирование SRS не изменились. Программирование работает без сервиса ИИ.

## Известные проблемы

Десктопные сборки не подписаны. Windows может показывать Unknown Publisher. На macOS при первом запуске откройте приложение через контекстное меню.

Неподписанное приложение macOS не может устанавливать обновления автоматически. Скачайте новую версию со страницы релиза.
