# LioraLang 0.7.1

**English** | [Русский](v0.7.1.ru.md) | [Polski](v0.7.1.pl.md)

Programming cards are easier to create, and code can belong to either the question or the answer.

## Improved

- The New deck menu offers Programming directly, and the editor puts subject selection first.
- Fields follow card order: term or question, optional code, then a multiline answer.
- Choose With question or With answer for code. Answer-side code stays hidden until the flip.
- Long code lines wrap to fit, with line numbers at the start of each original line.
- Enter adds a line in the answer; Ctrl/Command + Enter adds the card.
- Programming uses card labels in the editor, deck details and Learn, in all twelve interface languages.

## Fixed

Offline reopening keeps cached styles even when request headers differ. Quick add preserves code and its side and does not parse programming text as a vocabulary list. Add card fits the compact landscape toolbar. Local previews no longer request the Vercel-only analytics script.

## Compatibility

Answer-side code uses package format 3 and requires 0.7.1 or the updated website. Older apps reject it rather than exposing the answer. Other programming decks remain format 2; language decks remain format 1.

Language cards and SRS scheduling are unchanged. Programming still works without an AI service.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
