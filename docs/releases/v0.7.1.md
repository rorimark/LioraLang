## What’s New in v0.7.1

Creating programming cards is easier, and code can now belong to either the question or the answer.

### Improved

- Open a Programming deck directly from New deck. The subject choice comes first in the editor
- Card fields follow the reading order: term or question, optional code, then a multiline answer
- Choose With question or With answer for the code. Answer-side code stays hidden until the card is flipped
- Long code lines wrap to fit the screen, with line numbers aligned to the beginning of each original line
- Enter inserts a new line in an answer; Ctrl/Command + Enter adds the card
- Programming uses card labels in the editor, deck details and Learn, with translations in all 12 interface languages

### Fixed

- Offline reopening no longer misses cached build styles when request headers differ
- Quick add preserves existing code and its selected side, and does not mistake programming text for a vocabulary list
- The Add card button fits the compact landscape toolbar
- Local web previews no longer request a Vercel-only analytics script

Language decks and SRS scheduling are unchanged. Programming cards continue to work without an AI service.

### Compatibility and known issues

- Decks with answer-side code require 0.7.1 or the updated website. They use deck format 3; older apps refuse them instead of losing the code placement and exposing the answer. Other programming decks stay format 2, and language decks stay format 1
- Desktop builds are not code-signed. Windows may show Unknown Publisher; on macOS, open the app for the first time with right-click → Open
- The unsigned macOS app cannot install updates automatically. Download this version from the release page
