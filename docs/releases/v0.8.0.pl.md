# LioraLang 0.8.0

[English](v0.8.0.md) | [Русский](v0.8.0.ru.md) | **Polski**

Wersja dodaje sugestie AI dla programowania i opcjonalne obrazki obok zwykłych kart językowych.

## Sugestie programowania

Poproś o maksymalnie trzy propozycje na podstawie terminu, pytania lub kodu w edytorze albo szybkim dodawaniu. Przed zastosowaniem sprawdź odpowiedź, stronę kodu, trudność, notatki i tagi. Uzupełniane są tylko puste pola, zapis pozostaje osobnym działaniem.

Funkcja korzysta z istniejącego konta i dziennego limitu. Pokazuje brak sieci, logowanie, limit i błędy. Edycja lub zmiana talii odrzuca spóźnione odpowiedzi. Powtórki programowania są lokalne i nie wywołują AI.

## Obrazki na kartach językowych

Zwykła karta językowa może teraz mieć obrazek obok słowa i tłumaczenia. Ustawienia sesji oferują Tekst → tłumaczenie lub Obrazek → słowo. Karty bez obrazu używają tekstu, a oba widoki mają jeden harmonogram powtórek.

Funkcja korzysta z przechowywania obrazów, synchronizacji i eksportu talii obrazkowych.

## Profile przedmiotów

Profile opisują pola, wygląd, widoki nauki i osobne możliwości AI. Formularze i walidacja AI używają wspólnych definicji pól. Wybór przedmiotu obsługuje większy katalog, a import odrzuca nieznane przedmioty zamiast tracić pola.

## Zgodność

Karty językowe z opcjonalnymi obrazami używają formatu pakietu 4. Starsze aplikacje odrzucają go, aby nie tracić obrazów. Zwykłe talie językowe zachowują format 1. Programowanie używa 2 lub 3 zależnie od strony kodu.

Planowanie SRS i FSRS pozostaje bez zmian.

## Znane problemy

Wydania desktop nie są podpisane. Windows może pokazywać Unknown Publisher. Na macOS przy pierwszym uruchomieniu otwórz aplikację przez menu kontekstowe.

Niepodpisana aplikacja macOS nie może automatycznie instalować aktualizacji. Pobierz nową wersję ze strony wydania.
