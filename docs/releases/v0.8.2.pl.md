# LioraLang 0.8.2

[English](v0.8.2.md) | [Русский](v0.8.2.ru.md) | **Polski**

Funkcje AI otrzymują osobne przełączniki w Ustawienia → Asystent AI.

Automatyczne sugestie słów i wyjaśnienia po Again można ustawiać osobno od sugestii kart, uzupełniania list, generowania według tematu i opisów talii. Wyłączenie funkcji anuluje jej żądanie i blokuje spóźniony wynik; inne włączone funkcje pozostają dostępne.

Wybory zachowują się między uruchomieniami. Jeśli AI było wcześniej wyłączone, ta wersja pozostawia wszystkie sześć funkcji wyłączonych do osobnego włączenia. Ustawienia rozróżniają działania automatyczne i wywoływane przyciskiem oraz pokazują wspólny dzienny limit. Nowe kontrolki są dostępne we wszystkich dwunastu językach.

## Znane problemy

Wydania desktop nie są podpisane. Windows może pokazywać Unknown Publisher. Na macOS przy pierwszym uruchomieniu otwórz aplikację przez menu kontekstowe.

Niepodpisana aplikacja macOS nie może automatycznie instalować aktualizacji. Pobierz nową wersję ze strony wydania.
