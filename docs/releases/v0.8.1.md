# LioraLang 0.8.1

**English** | [Русский](v0.8.1.ru.md) | [Polski](v0.8.1.pl.md)

Programming suggestions work again after correcting invalid empty enum values in the Gemini output schema.

## Changed

- Choose a subject in the editor or when creating a deck from Learn. The separate Programming entry was removed from New deck.
- Subject decks have an explicit answer language. AI answers and notes follow it, independently of interface language or technology.
- Changing the answer language does not translate existing cards.
- Quick creation preserves the subject, technology, answer language and code side after reopening. Changing the subject cancels pending suggestions.

## Compatibility and checks

Decks with an explicit answer language require this version or newer and use package format 5. Older editors reject them rather than discarding the setting.

Validation covered contracts, storage, offline creation and review, quick creation and AI suggestions in the browser, plus a live Hoisting suggestion through the production app.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
