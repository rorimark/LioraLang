# LioraLang v0.8.1

Card suggestions now work for Programming decks: the Gemini output schema no longer contains invalid empty enum values.

- Choose the deck subject inside the editor or when creating a new deck from Learn. The separate Programming item was removed from the New deck menu.
- Subject decks have an explicit answer language. AI answers and notes use that choice, independently of the interface language or technology name. Existing cards are not translated when the setting changes.
- Quick creation keeps the subject, technology, answer language and code placement through saving and reopening. Changing the subject cancels pending suggestions.
- Exported decks with an answer language require this version or newer, so older editors cannot silently discard the setting.

Validation: automated contract and storage tests, offline creation and review, browser checks for quick creation and AI suggestions, and a live Hoisting suggestion through the production app.

Known issues: desktop builds are not code-signed. macOS requires downloading the new release manually.
