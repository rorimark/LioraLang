# LioraLang 0.8.0

[English](v0.8.0.md) | **Русский** | [Polski](v0.8.0.pl.md)

Версия добавляет предложения ИИ для программирования и необязательные картинки рядом с обычными языковыми карточками.

## Предложения программирования

Запросите до трёх вариантов по термину, вопросу или коду в редакторе или быстром добавлении. Перед применением проверьте ответ, сторону кода, сложность, заметки и теги. Заполняются только пустые поля, сохранение остаётся отдельным действием.

Функция использует существующий аккаунт и дневную квоту. Отображаются офлайн, вход, квота и ошибки. Редактирование и смена колоды отбрасывают поздние ответы. Повторение программирования остаётся локальным и не вызывает ИИ.

## Картинки в языковых карточках

Обычная языковая карточка теперь может содержать картинку рядом со словом и переводом. В сессии доступны «Текст → перевод» и «Картинка → слово». Без картинки используется текст; оба представления имеют одно расписание повторений.

Используются те же хранение изображений, обмен и экспорт, что у картинных колод.

## Профили предметов

Профили описывают поля, оформление, представления учёбы и отдельные возможности ИИ. Формы и проверка ИИ используют общие определения полей. Выбор предмета поддерживает расширенный каталог, импорт отклоняет неизвестные предметы вместо потери полей.

## Совместимость

Языковые карточки с необязательными картинками используют формат пакета 4. Старые приложения отклоняют его, чтобы не потерять картинки. Обычные языковые колоды остаются в формате 1. Программирование использует 2 или 3 по стороне кода.

Планирование SRS и FSRS не изменилось.

## Известные проблемы

Десктопные сборки не подписаны. Windows может показывать Unknown Publisher. На macOS при первом запуске откройте приложение через контекстное меню.

Неподписанное приложение macOS не может устанавливать обновления автоматически. Скачайте новую версию со страницы релиза.
