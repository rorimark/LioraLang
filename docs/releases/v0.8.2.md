# LioraLang 0.8.2

AI functions now have independent switches in Settings → AI assistant. Automatic word suggestions and explanations after Again are separate from card suggestions, list completion, topic collection, and deck descriptions.

- Turning off a function cancels its pending request and prevents late results from filling fields. Other enabled functions remain available.
- Settings persist across restarts. If AI was previously disabled, all six functions stay disabled until you enable them individually.
- The settings page separates automatic actions from actions requested by button and shows the shared daily allowance. All 12 interface languages are supported.

## Known issues

The desktop builds are not code-signed. Windows may show Unknown Publisher; on macOS, open the app the first time through the context menu. macOS users need to download the new version from this release page because automatic updates require signing.
