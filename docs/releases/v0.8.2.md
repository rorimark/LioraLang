# LioraLang 0.8.2

**English** | [Русский](v0.8.2.ru.md) | [Polski](v0.8.2.pl.md)

AI functions get separate switches in Settings → AI assistant.

Automatic word suggestions and explanations after Again can be controlled separately from card suggestions, list completion, topic generation and deck descriptions. Turning off a function cancels its request and blocks late results; other enabled functions remain available.

Choices persist across restarts. If AI was previously disabled, this version leaves all six functions disabled until they are enabled individually. Settings distinguish automatic actions from actions requested by a button and show the shared daily allowance. All twelve interface languages include the new controls.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
