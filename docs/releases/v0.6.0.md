# LioraLang 0.6.0

**English** | [Русский](v0.6.0.ru.md) | [Polski](v0.6.0.pl.md)

This release adds AI help for language cards and improves the deck editor, account tools and Hub.

## AI features

- Type a word or translation to get suggestions for empty fields: translation, third language, CEFR level, part of speech, two examples and tags. Tab accepts the suggestion; existing input is preserved.
- Fill a pasted list with translations, levels, parts of speech, examples and tags, with suggested spelling corrections.
- Generate a language deck by topic, level and word count, then review the drafts before adding them.
- Get a short memory hint after Again. It stays until the next grade.

In this version, AI requires sign-in and an internet connection and can be disabled in Settings → New words. Gemini receives the material and deck languages needed for the request.

## Account and Hub

Picture-side decks can now be published to the Hub. Account → Security can delete an account, its cloud library, progress and published decks while keeping local decks on the device. Users can report a Hub deck; several independent reports hide it for review.

## Editor and study

The editor keeps an add-word row available, saves existing deck edits automatically and supports editing a word in place. Fields are arranged around the two card sides. The third language has its own list column and editor field.

Deck details show learned material and reviews due. Session settings use the same controls as the main settings page and fit a phone screen. Learn uses the same name throughout the app.

## Fixed

- Quick add accepts words with a picture on the first side.
- Pictures upload and sync with the account.
- Starting with a translation keeps the cursor in that field.
- Settings have separate scrolling for the section list and content.
- Sticker labels fit inside their stickers.

## Known issues

Desktop builds are not code-signed. Windows may show Unknown Publisher. On macOS, use the context menu to open the app for the first time.

The unsigned macOS app cannot install updates automatically. Download the new version from the release page.
