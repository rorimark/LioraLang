# LioraLang 0.6.0

[English](v0.6.0.md) | **Русский** | [Polski](v0.6.0.pl.md)

Версия добавляет помощь ИИ для языковых карточек и улучшает редактор колод, инструменты аккаунта и Hub.

## Функции ИИ

- Введите слово или перевод, чтобы получить предложения для пустых полей: перевод, третий язык, уровень CEFR, часть речи, два примера и теги. Tab принимает предложение; существующий ввод сохраняется.
- Дополните вставленный список переводами, уровнями, частями речи, примерами и тегами, с предложениями исправления написания.
- Сгенерируйте языковую колоду по теме, уровню и количеству слов, затем проверьте черновики перед добавлением.
- Получите короткую подсказку для запоминания после Again. Она остаётся до следующей оценки.

В этой версии ИИ требует входа и сети, отключается в «Настройки → Новые слова». Gemini получает материал и языки колоды, необходимые для запроса.

## Аккаунт и Hub

Картинные колоды теперь можно публиковать в Hub. «Аккаунт → Безопасность» удаляет аккаунт, облачную библиотеку, прогресс и публикации, сохраняя локальные колоды на устройстве. Можно пожаловаться на колоду Hub; несколько независимых жалоб скрывают её для проверки.

## Редактор и учёба

В редакторе постоянно доступна строка добавления; изменения существующей колоды сохраняются автоматически, слово можно править на месте. Поля расположены по двум сторонам карточки. Третий язык имеет отдельную колонку списка и поле редактора.

Страница колоды показывает изученный материал и доступные повторения. Настройки сессии используют общие контроли и помещаются на телефоне. Название Learn единообразно по всему приложению.

## Исправлено

- Быстрое добавление принимает слова с изображением на первой стороне.
- Картинки загружаются и синхронизируются с аккаунтом.
- Начало ввода с перевода сохраняет курсор в этом поле.
- Список разделов и содержимое настроек прокручиваются отдельно.
- Подписи стикеров помещаются внутри.

## Известные проблемы

Десктопные сборки не подписаны. Windows может показывать Unknown Publisher. На macOS при первом запуске откройте приложение через контекстное меню.

Неподписанное приложение macOS не может устанавливать обновления автоматически. Скачайте новую версию со страницы релиза.
