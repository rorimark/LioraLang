# LioraLang 0.8.3

[English](v0.8.3.md) | [Русский](v0.8.3.ru.md) | **Polski**

Ustawienia → Asystent AI zaczynają się teraz od głównego przełącznika. Osobne funkcje są dostępne, gdy jest włączony.

Wyłączenie głównego przełącznika zatrzymuje oczekujące żądania i blokuje automatyczne wskazówki oraz ręczne generowanie. Indywidualne wybory są zachowane i przywracane po ponownym włączeniu AI. Główne ustawienie zachowuje się między uruchomieniami i przy migracji uwzględnia wcześniejszą wspólną preferencję.

Przełącznik i wyjaśnienie są dostępne we wszystkich dwunastu językach interfejsu.

## Znane problemy

Wydania desktop nie są podpisane. Windows może pokazywać Unknown Publisher. Na macOS przy pierwszym uruchomieniu otwórz aplikację przez menu kontekstowe.

Niepodpisana aplikacja macOS nie może automatycznie instalować aktualizacji. Pobierz nową wersję ze strony wydania.
